# Raumplan

Räume mit der Handykamera (Chrome auf Android, ARCore) vermessen und als 2D-Grundriss mit Maßen speichern.

- Ecken am Boden antippen, Raum schließt sich an der ersten Ecke
- Mehrere Räume in einem Durchgang → gemeinsamer Plan
- Türen messen; beim nächsten Raum die Durchgangstür wählen (leuchtet grün im Kamerabild und im Plan)
- Gespeicherte Pläne weitermessen: Tür im Plan wählen, neu antippen → neue Räume liegen passend an
- „Räume angleichen“: Wände rechtwinklig, Räume parallel und bündig (rückgängig machbar)
- Manuelle Eingabe für iPhone/ohne AR
- Wandlängen, Flächen, Export als PNG/SVG
- Beispielansicht: `#demo` an die Adresse anhängen
